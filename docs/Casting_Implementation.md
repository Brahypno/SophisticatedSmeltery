# 便携浇筑模块

## 当前行为（2026-10-24 扩展）

- 焦黑物品 ID 为 `seared_casting_upgrade` / `advanced_seared_casting_upgrade`，对应**焦黑浇筑升级 / 高级焦黑浇筑升级**；焦褐为 `scorched_casting_upgrade` / `advanced_scorched_casting_upgrade`，对应**焦褐浇筑升级 / 高级焦褐浇筑升级**。用户明确当前为开发阶段，直接重命名，不做旧 ID 兼容或迁移。焦黑、焦褐的中文依据当前依赖匠魂的 `zh_cn.json`，对应焦黑/焦褐铸件台、铸造盆。
- 每份浇筑升级在模板旁有独立开关。用户确认关闭仅停止新的手动/自动浇筑，已开始的冷却与成品交付继续；仍允许退回半满残液。包装器保留宿主调度，开关单独保存，不使用会将冷却一起排除的原生禁用调度。
- **不要求安装熔炼升级**。供液顺序为当前炉底、背包储罐升级；炉内不查找上层流体。某来源无法匹配或无法容纳其产物时尝试下一来源，同一批可从后续储罐补足同种液体，不混液。退液先尝试炉内，再按实际可接收量退回储罐，不经过流体销毁升级。
- 普通版仅手动，高级版才有自动；四种物品均默认开启、手动、成品留槽。成品去向可切换为**输出槽堆积 / 优先包内**。输出槽只堆积同物品、同 NBT 且未达堆叠上限的产物，浇入前检查容量。包内先尝试所有非熔炼槽，再尝试熔炼槽，背包放不下的成品保留并重试。原生 `switchSlots()` 配方保持原槽位策略，包内模式也能收取落在输入位的实际产物，不把可重复模具当成成品搬走。
- 自动连续堆积时，已经完成的输出可以在下一批冷却期间取走；正在使用的模具仍锁定，不能因此移走模具或拆卸有液体的升级。
- 焦褐台、盆复用原生配方，并沿用原生 `requireCast`：输入必须有物品；原生金栏杆、金平台等空模具 tag 仍按无模具上下文匹配。焦黑版本仍可空槽浇筑。
- 焦褐版可放入一个模具后点击台/盆切换图标旁的**锁头图标**，记住物品与 NBT；耗尽后从当前背包普通库存补入一个完全匹配的物品。缺料时等待，添加材料后自动恢复；再次点击解除锁定。图标复用 Minecraft 原生 `LockIconButton` 的开锁、闭锁、悬停及禁用材质，悬停提示显示用途与锁定物品，去掉原先底部整行文字按钮。可重复模具不会被额外消耗，补料不递归访问嵌套背包。
- 浇筑按钮放在独立产物预览的下方，位于右侧 `x+100,y+74`；台/盆切换和独立预览的位置保持原样。底部退液、自动、产物去向三个 18×18 图标在 `x+8/54/100,y+92` 等距排列，相邻间隔均为 28 像素。分别使用对应材质的原生浇注口、原生返回箭头、绿/灰循环箭头、背包/槽位。箭头、循环和去向图标及按钮背景复用精妙核心原生 GUI 材质；状态及说明放在悬停提示中，禁用动作会变暗。普通版仍不显示自动图标。面板统一为 128×115，不新增图片文件。
- 焦褐普通配方沿用焦黑的 `BFT / CUC / FCF` 排列，替换为焦褐盆、浇注口、台、浇筑道；高级版沿用钻石/金锭/红石升阶布局，使用共用升阶序列化器，独立复制模具锁、开关、产物去向及其余 NBT。两级都有配方解锁与本地模型，图标取对应焦黑/焦褐台的原生上表面。
- 输入/输出空槽悬停显示“输入”/“输出”；有物品时只显示原来的物品提示，不追加用途标签。中间使用匠魂原生灰色箭头，表示输入→液体区→输出，独立预览仍使用原有预览提示。
- 四种浇筑升级均列入 `sophisticatedbackpacks:upgrade` 标签。焦褐版此前漏列该标签，导致真实背包升级槽拒绝安装；修复后通过实际菜单槽取出、重新安装两种焦褐升级验证，测试不再只依赖直接设置升级槽。

本轮服务端与客户端验证状态、日志和人工待验收项以 [Implementation_Status.md](Implementation_Status.md) 为准。

浇筑回归按用户要求由 32 个入口精简为 16 个，原生对照、半满/冷却重载、拆卸、数量守恒、输出去向和模具锁等行为检查继续保留。普通 JSON 配方排布不再单独长期测试；自定义升阶的状态独立复制及客户端配方包保留一项双材质矩阵回归。完整测试分类见上述状态文档。

## 扩展前实现与验证记录

以下为本轮扩展前的实现记录；“必须有控制器”“输出未取走不再注液”等旧行为已由上节替代，历史测试日志保留作为当时版本的证据。

`PortableCasting` 直接使用真实 `ICastingRecipe` 与 `ICastingContainer`，不创建浇筑方块实体，不运行世界 Tick，也不增加 Mixin。输入、独立输出和已浇入液体保存在该模块 NBT；炉内液体仍只由控制器持有，浇筑时从当前底层实际扣除。

已实现并通过原生对照测试的核心：

- 台/盆两种配方类型、原生空模具 tag、精确用液量及冷却时间。
- `assemble()` 动态产物、`isConsumed(context)` 及无红石状态下的 `switchSlots()` 原生槽位策略；保留结果 NBT。
- 半满时等待，不能移动模具或切换台/盆；只退回目标炉子可容纳的液体，满炉不丢液。
- 有效配方冷却中不能退液；冷却和半满状态保存/恢复；输出未取走时不再注液，不进入背包熔炼输入。
- 数据包移除运行配方后停止产出，保留液体并允许退回，不继续使用旧缓存。
- 退液入口也会先恢复当前世界的配方上下文：重载后尚未收到首次宿主 Tick 时，不能将正在冷却的有效配方误当成半满残液退回。

测试 `CastingGameTests` 将真实原版浇筑台/盆放在测试世界，向原版和便携模块注入相同液体，逐 Tick 对比冷却及两个槽位产物。包含可重复金模具、一次性沙模具、无模具铁块，以及原生储罐填充配方的动态 NBT/槽位交换。另检查半满退液、冷却重载、移除配方及预览缓存失效。核心测试已纳入下述完整回归。

## 背包升级与界面

用户已经确认：关闭加热后继续浇筑与冷却，有残液或正在冷却的浇筑升级不能拆下。

已注册普通 `casting_upgrade` 与高级 `advanced_casting_upgrade`，共用原生浇筑核心、容器和设置页，可安装多份，默认手动。手动按钮从炉内当前底层流体浇入一个原生配方的用量；**仅高级版**可启用自动，在有空闲输出且液体或模具变化后重试，不逐 Tick 重查失败配方。普通版界面不显示自动按钮，服务端还会检查物品等级，旧 NBT 或手工发送自动动作均不能越级。冷却始终按正常宿主 Tick 推进，不受加热开关影响。成品留在该升级独立输出槽，避免自动回炉。

GUI 提供模具槽、独立输出槽、台/盆模式图标、配方预览、浇筑流体柱、竖向冷却条及浇筑/退液按钮，高级版额外提供自动切换。预览按模具、流体、模式和配方重载失效缓存，不逐帧遍历配方。

普通版的手动浇筑按钮占满该行；高级版在同一行提供浇筑与自动切换。两版图标将原生焦黑浇筑台朝上的模型面投影到底板中心，高级边框复用精妙高级磁铁纹理的外框，不包含中心磁铁图案。没有新增图片或 Mixin，资源包中的上表面和边框纹理随模型重载生效。

普通合成是用户图中的 `BFT / CUC / FCF`：B 为焦黑铸件盆、F 为焦黑浇注口、T 为焦黑铸件台、C 为焦黑浇筑道、U 为精妙空白升级。高级合成为 ` D  / GUG / RRR`，D 钻石、G 金锭、U 普通浇筑升级、R 红石；使用精妙原生升阶状态转移并复制 NBT 为独立所有权，同时保留普通有序配方书显示。两张配方均有解锁进度。

每次实际浇入/退回液体都保存控制器和浇筑升级双方状态。浇筑模具的 GUI 改动即时保存，Tick 内合并保存；增删其他升级导致原生包装器重建时不能复制液体或丢失模具。

精妙核心的物品移除检查没有升级槽位参数，因此增加一个仅作用于浇筑升级的 `UpgradeHandler.extractItem` 入口检查。模拟提取与真实提取均逐槽检查残液；替换另由带槽位参数的原生检查保护。不锁住其他空闲浇筑升级，不修改其他升级的提取。
