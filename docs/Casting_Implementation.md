# 便携浇筑模块

`PortableCasting` 直接使用真实 `ICastingRecipe` 与 `ICastingContainer`，不创建浇筑方块实体，不运行世界 Tick，也不增加 Mixin。输入、独立输出和已浇入液体保存在该模块 NBT；炉内液体仍只由控制器持有，浇筑时从当前底层实际扣除。

已实现并通过原生对照测试的核心：

- 台/盆两种配方类型、原生空模具 tag、精确用液量及冷却时间。
- `assemble()` 动态产物、`isConsumed(context)` 及无红石状态下的 `switchSlots()` 原生槽位策略；保留结果 NBT。
- 半满时等待，不能移动模具或切换台/盆；只退回目标炉子可容纳的液体，满炉不丢液。
- 有效配方冷却中不能退液；冷却和半满状态保存/恢复；输出未取走时不再注液，不进入背包熔炼输入。
- 数据包移除运行配方后停止产出，保留液体并允许退回，不继续使用旧缓存。
- 退液入口也会先恢复当前世界的配方上下文：重载后尚未收到首次宿主 Tick 时，不能将正在冷却的有效配方误当成半满残液退回。

测试 `CastingGameTests` 将真实原版浇筑台/盆放在测试世界，向原版和便携模块注入相同液体，逐 Tick 对比冷却及两个槽位产物。包含可重复金模具、一次性沙模具、无模具铁块，以及原生储罐填充配方的动态 NBT/槽位交换。另检查半满退液、冷却重载和移除配方。7 项浇筑核心测试及完整 37 项回归通过，最新日志 `build/continuation-final-tests.log`。

此提交为独立可验证的浇筑核心，尚未注册浇筑升级物品、设置页和宿主 Tick。关闭加热时的浇筑行为、含液体/冷却时的拆卸规则已提问，等待用户确认后接入；不能据核心测试将整个浇筑升级标为完成。自动/手动切换和未执行配方的退液按钮按已确认设计接入，配方材料继续暂缓。
