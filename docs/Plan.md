## 熔炼槽加宽（2026-10-25：暂缓）

用户确认：当前先不实现，清除本轮本地临时试排与截图测试改动，待用户要求继续时再开发。

目标行为：

- 仅前 X 个实际熔炼槽使用匠魂原生 22×18 槽框；其余普通库存保持 18×18，物品图标均保持 16×16。
- 加宽槽内使用完整 3 像素宽的原生热量条，所有状态与底槽宽度一致，状态颜色与边框之间不留一像素空隙。
- 实际物品位置、点击、拖动、悬停提示和槽框一致；支持熔炼区在一行中途结束。

实现边界：

- 当前 Sophisticated Core 的 `StorageScreenBase` 将库存槽距、背景宽度写为 18 像素；`InventoryScrollPanel` 同样按 18 像素计算宽度、裁剪及位置。
- 已检查的升级 GUI 扩展接口没有对应的布局配置入口。保留原生背包界面和滚动机制时，需要额外的客户端 Mixin 适配上述两处；当前未新增这些 Mixin。
- 仅对装有熔炼升级的界面生效，普通背包、服务端库存与熔炼规则保持原有行为。
- 正式实现还需处理搜索过滤、排序、滚动与非滚动界面、窗口缩放、储罐等升级占列，以及安装/移除升级后的布局重建。

恢复开发时的验收：

1. 先将行为接入 `src/main` 的正式实现，再运行实际背包界面验证。此前临时界面的试排截图不代表正式功能已经实现。
2. 验证混合槽框、真实点击位置、滚动边界和三列热量条像素；确认普通槽及普通背包不受影响。
3. 只截同一背包中熔炼槽与普通槽交界的局部，两区放相同物品供对照。
4. Git 提交正式代码及必要说明；本地截图专用代码、截图、日志和测试存档不作为交付内容提交。
